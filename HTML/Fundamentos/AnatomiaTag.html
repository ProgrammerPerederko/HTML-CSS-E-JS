Anatomia de uma Tag HTML

Para criar uma página na internet utilizando HTML é necessário conhecer como funciona a estrutura das tags. Elas são responsáveis por organizar e identificar cada elemento presente em um documento.

O que é uma tag?

Uma tag é uma marcação utilizada para informar ao navegador qual é a função de determinado conteúdo dentro da página. Existem tags para títulos, parágrafos, imagens, listas, tabelas, formulários e muitos outros elementos.

Estrutura de uma tag

Grande parte das tags HTML é composta por uma abertura, um conteúdo e um fechamento. 

<p>
    Este é um parágrafo.
</p>

Nesse exemplo, a tag <p> indica o início do parágrafo e </p> indica o seu término. O texto escrito entre elas é chamado de conteúdo. :contentReference[oaicite:1]{index=1}

Tag de abertura

A tag de abertura informa onde o elemento começa. Ela é formada pelo sinal de menor que (<), seguido do nome da tag e finalizada pelo sinal de maior que (>). 

<h1>

Tag de fechamento

A maioria das tags possui um fechamento. A diferença é que antes do nome da tag existe uma barra (/), indicando o encerramento daquele elemento. 

</h1>

Isso ajuda o navegador a identificar onde determinado conteúdo termina.

Elemento HTML

Um elemento HTML é formado pela tag de abertura, pelo conteúdo e pela tag de fechamento. 

<h1>
    Alimentação Saudável
</h1>

Nesse caso, todo o conjunto representa um único elemento HTML. :contentReference[oaicite:2]{index=2}

O que são atributos?

Os atributos servem para fornecer informações adicionais sobre uma determinada tag. Eles são escritos dentro da tag de abertura e são compostos por um nome e um valor. 

<img src="logo.png">

Nesse exemplo, src é o nome do atributo e logo.png representa o seu valor. O atributo informa qual imagem será carregada pelo navegador. :contentReference[oaicite:3]{index=3}

Outro exemplo de atributo

<video velocidade="2">

Dependendo da tag utilizada, diferentes atributos podem ser aplicados para modificar seu comportamento ou fornecer informações adicionais.

Importância do fechamento das tags

Fechar corretamente uma tag é uma boa prática de programação, pois garante que o navegador interprete corretamente a estrutura do documento.

Quando uma tag não é fechada corretamente, podem ocorrer problemas na organização da página, dificultando tanto a manutenção quanto a leitura do código. 

<h1>
    Alimentação Saudável
</h1>

Esse texto está fora da tag.

No exemplo acima, apenas o título pertence ao elemento <h1>. O texto seguinte já faz parte do restante do documento. :contentReference[oaicite:4]{index=4}

Conclusão

Compreender a anatomia de uma tag é um dos primeiros passos para aprender HTML. Saber identificar a abertura, o fechamento, o conteúdo e os atributos facilita o desenvolvimento de páginas organizadas, semânticas e de fácil manutenção.

Esse conhecimento serve como base para aprender outros recursos do HTML, além de facilitar o estudo de CSS e JavaScript futuramente.
